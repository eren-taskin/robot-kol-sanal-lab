# Başlarken

Bu klasör, robot kol projesinin başlangıç paketidir. İçindekileri olduğu gibi GitHub deposunun ana klasörüne kopyalayın, sonra GitHub Desktop'ta Commit ve Push yapın.

| Dosya | Ne işe yarar | Kim okur |
|---|---|---|
| `SPEC.md` | Teknik şartname: bütün parametreler, denklemler, testler | Araçlar ve ekip |
| `PROJECT.md` | Mimari, kodlama kuralları, çalışma düzeni, durum tablosu | Araçlar ve ekip |
| `TASKS.md` | Araçlara yapıştırılacak görev istemleri (T01–T11) | Siz, sırayla |
| `docs/YOL_HARITASI.md` | Projenin bütünü, zorluklar, haftalık plan (Türkçe) | Ekip |
| `docs/RoboticArm_LiteratureReview_v6.pdf` | Raporunuz; SPEC'teki denklem numaraları buna atıf yapar | Herkes |
| `reference/arm_reference.py` | Modelin bağımsız Python hesabı | Ekip (isteğe bağlı) |
| `reference/test_vectors.json` | C# testlerinin karşılaştıracağı doğrulanmış sayılar | Testler |
