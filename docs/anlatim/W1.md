4. *Iyy neden ayrı önemli?* — Eğim eklemleri y ekseni etrafında döner; eğim bloğundaki J_i, Iyy'dir.
5. *Rotor eylemsizliği neden 0?* — Veri sayfasında yok; bilinmeyen bir değeri uydurmak yerine deney parametresi olarak 0 bırakıldı.

**(b) Önemli satırlar.**

```csharp
double cx = (m4 * c4x + mp * tx) / mNew;
```


```csharp

```
Çarpım eylemsizliği I = m(|d|²·1 − d·dᵀ) formülünün köşegen dışı terimidir; işaret eksi gelir.

```csharp
p.ComAngleRad[3] = Math.Atan2(-cz, cx);
```
Yeni merkez tablodaki (ℓ, ε) biçimine geri çevrilir, böylece M ve g formülleri hiç değişmeden kullanılır.

2. *Ixx neden yalnız d_z² alır?* — d'nin y bileşeni sıfır; |d|² − d_x² = d_z².
3. *Yük 0 ise?* — Kopya değişmeden döner.
4. *Asıl parametreler değişir mi?* — Hayır, `arm.Clone()` üzerinde çalışılır.
5. *Doğruluğu nasıl biliyoruz?* — Testlerde 0,3 ve 0,5 kg ile M, c + g ve q̈ eski çekirdekle 1e-9 bağıl hatayla örtüşür; test vektörlerindeki 0,5 kg pozları da tutar.

## Dynamics/MassMatrixFormulas.cs

**(a) Ne yapar.** Kütle matrisi M(q)'yu raporun kapalı formlarıyla (eş. (14)–(17), SPEC §5.3) her elemanı ayrı satırda hesaplar. Ayrıca ∂M/∂q'yu analitik olarak (elle türetilmiş formüllerle) verir; Coriolis terimi bundan kurulur. Taban eklemi eğim eklemleriyle bağlaşmaz (M12 = M13 = M14 = 0).

**(b) Önemli satırlar.**

```csharp
m11 += p.MassKg[i] * rho[i] * rho[i]
     + p.IxxKgM2[i] * s * s + p.IzzKgM2[i] * c * c - 2.0 * p.IxzKgM2[i] * s * c;
```
Taban ekseninin eylemsizliği: her uzvun nokta kütle payı (m ρ²) artı uzvun kendi eylemsizliğinin, θ kadar eğilmiş çerçevede düşey eksene izdüşümü.

```csharp
double k23 = p.L2M * p.L3M * Math.Cos(q[2] + b);
```
Bağlaşım terimleri yalnız göreli açılara (q3, q4) bağlıdır; q2 kolu bütünüyle döndürdüğü için eğim bloğunu değiştirmez.

```csharp
double M23 = J3 + J4 + m3 * (l3 * l3 + h) + m4 * (L3 * L3 + l4 * l4 + 2.0 * k34 + k23 + k24);
```
SPEC §5.3'teki satırın birebir karşılığı. Her eleman kendi adıyla bir satırdır.

```csharp
double dM23 = m3 * dh + m4 * (2.0 * dk34 + dk23 + dk24);
```
Aynı satırın türevi: J ve m ℓ² gibi sabitler türevde kaybolur, yalnız bağlaşım terimlerinin türevleri kalır.

```csharp
d -= p.L3M * Math.Sin(t[2]);
```
`RadiusDerivative` içinde: ρ4'teki L3 cos θ3 payının türevi. θ3 hem q2'ye hem q3'e bağlı olduğundan bu terim k = 1 ve k = 2 için eklenir.

**(c) Sorular.**
1. *M neden simetrik?* — Kinetik enerji ½ q̇ᵀ M q̇ ikinci dereceden bir formdur; simetrik parçası yeterlidir. Kod `SetSymmetricBlock` ile M23 = M32 yazar.
2. *Neden M1k = 0?* — Kütle merkezleri ve eylemsizlik çarpımları kolun düşey düzlemindedir (Ixy = Iyz = 0); taban dönüşü ile eğim hareketleri arasında kinetik enerji çapraz terimi oluşmaz.
3. *Türev neden sayısal değil?* — Analitik türev tamdır ve açıklanabilir; testte merkezi farkla 1e-10 içinde karşılaştırılır.
4. *dM[0, *, *] neden sıfır?* — M, q1'e bağlı değildir; kolu taban etrafında döndürmek eylemsizliği değiştirmez.
5. *Rotor eylemsizliği nereye eklenir?* — `Compute` sonunda köşegene N²·Jm; sabit olduğundan türeve girmez.

## Dynamics/ArmDynamics.cs

**(a) Ne yapar.** Hareket denklemi M q̈ + c + g = τ − τf'nin (eş. (11)) her terimini ayrı metotla hesaplar ve ileri dinamikle q̈'yı bulur. Kinetik ve potansiyel enerjiyi de verir; enerji testleri ve grafikler bunları kullanır.

**(b) Önemli satırlar.**

```csharp
double christoffel = 0.5 * (dM[i, k, j] + dM[j, k, i] - dM[k, i, j]);
sum += christoffel * qd[i] * qd[j];
```
Eş. (13): Christoffel sembolü c_ijk = ½(∂M_kj/∂q_i + ∂M_ki/∂q_j − ∂M_ij/∂q_k). `dM[a, b, c]` = ∂M_bc/∂q_a olduğundan ilk terim `dM[i, k, j]`'dir. Hızların çarpımı Coriolis (i ≠ j) ve merkezkaç (i = j) torklarını verir.

```csharp
double g4 = -g * m4 * l4 * Math.Cos(t[3] + e4);
double g3 = g4 - g * (m3 * l3 * Math.Cos(t[2] + e3) + m4 * p.L3M * Math.Cos(t[2]));
```
Eş. (18): bilekten başlanır; her eklem kendinden sonraki bütün kütlelerin ağırlık momentini taşır, bu yüzden g3, g4'ü içerir.

```csharp
f[i] = p.ViscousFrictionNmsPerRad * qd[i] + p.CoulombFrictionNm * Math.Tanh(qd[i] / p.FrictionSmoothingRadPerS);
```
Eş. (20): viskoz artı yumuşatılmış Coulomb sürtünmesi.

```csharp
b[i] = tau[i] - c[i] - g[i] - f[i];
return Small4x4.SolveSymmetricPositiveDefinite(m, b);
```
Eş. (21): q̈ = M⁻¹(τ − c − g − τf), ama ters alınmadan Cholesky ile çözülür.

**(c) Sorular.**
1. *c'nin birimi?* — N·m; dM (kg·m²/rad) × q̇² (rad²/s²).
2. *q̇ = 0 iken c?* — Sıfır; c hızların karesiyle orantılıdır.
3. *g(q) doğru mu, nasıl biliyoruz?* — Test, g'yi potansiyel enerjinin sayısal gradyanıyla (1e-8) karşılaştırır ve test vektörleriyle doğrular.
4. *Neden tanh?* — sign(q̇) sıfırda süreksizdir; çözücü küçük adımlarda titrer. tanh ωs = 0,1 rad/s ölçeğinde yumuşatır.
5. *Eski çekirdekle uyuşuyor mu?* — Evet: 200 rastgele durumda, 0/0,3/0,5 kg yük, Dünya ve Ay için M, c + g ve q̈ 1e-9 bağıl hatayla aynı.


**(c) Sorular.**

## Motor/DcMotor.cs

**(a) Ne yapar.** XM430-W350 servo motorunun gerilimden eklem torkuna modelidir: τ = N·Kt·(V − N·Ke·q̇)/R, önce gerilim ±12 V'a, sonra tork ±τmax'a kırpılır. Endüktans ihmal edilir. Veri sayfasında olmayan R, Kt, Ke; tutulma noktasından (4,1 N·m, 2,3 A, 12 V) ve yüksüz hızdan (46 rpm) türetilir.

**(b) Önemli satırlar.**

```csharp
m.ResistanceOhm = voltageV / stallCurrentA;
```
Tutulmada (q̇ = 0) zıt EMK yoktur; akımı yalnız direnç sınırlar: R = 12/2,3 = 5,217 Ω.

```csharp
m.BackEmfConstantVsPerRad = voltageV / noLoadSpeedRadPerS / gearRatio;
```
Yüksüzde τ = 0, yani V = N·Ke·q̇; N·Ke = 12/4,817 = 2,491 V·s/rad.

```csharp
double currentA = (v - GearRatio * BackEmfConstantVsPerRad * jointSpeedRadPerS) / ResistanceOhm;
```
Motor N kat hızlı döner; zıt EMK Ke·(N·q̇)'dir ve uygulanan gerilimden düşülür.

```csharp
return Math.Max(-torqueLimitNm, Math.Min(torqueLimitNm, tau));
```

3. *Zıt EMK kola ne yapar?* — b = (N·Kt)(N·Ke)/R ≈ 0,85 N·m·s/rad'lık viskoz sönüm gibi frenler; gerilim modu bu yüzden tork modundan çok daha serttir.
4. *Stall testi neden tam 4,1 verir?* — R ve Kt o noktadan türetildi: N·Kt·V/R = (4,1/2,3)·12/(12/2,3) = 4,1.
5. *Dişli oranı nereden gelir?* — `Xm430W350(gearRatio)` parametresi; simülatör kol parametrelerindeki N'yi verir.

## Solvers/Rk4Solver.cs

**(a) Ne yapar.** Klasik dördüncü mertebe Runge–Kutta (rapor eş. (22)): başta, iki kez ortada ve sonda dört eğim; 1-2-2-1 ağırlıklı ortalama. Laboratuvarın varsayılan çözücüsüdür.
