# Phase M1 Report — Phone Width (375 px) Responsive Layout

## 1. What Was Changed

- **`src/RobotArm.Web/Components/LiveReadout.razor`**:
  - Wrapped the 8-column joint readout table (`<table class="readout-table">`: `Eklem`, `q`, `qd`, `e`, `q̇`, `u`, `τ`, `Durum`) inside `<div class="table-scroll">` so wide numeric cells after a run scroll horizontally inside their own container instead of expanding the outer grid column past 375 px.
- **`src/RobotArm.Web/Components/SetupPanel.razor`**:
  - Wrapped `<table class="gains-table">` inside `<div class="table-scroll">`.
- **`src/RobotArm.Web/Components/DesignHelper.razor`**:
  - Wrapped `<table class="gains-table helper-table">` inside `<div class="table-scroll">`.
- **`src/RobotArm.Web/wwwroot/css/app.css`**:
  - Changed `.lab-workspace` responsive breakpoints (`@media (max-width: 1280px)` and `@media (max-width: 820px)`) to use `minmax(0, 1fr)` instead of `1fr` so CSS Grid tracks do not expand to the `min-content` width of child tables.
  - Added `min-width: 0; max-width: 100%;` to `.lab-shell`, `.lab-main`, `.col-setup`, `.col-centre`, `.col-readout`, `.panel-card`, `.setup-group`, `.field-row`, `.kv-item`, `.joint-limit-pill`, `.perf-cell`, `.stability-item`, `.readout-section`, and `.lab-analysis`.
  - Updated `.lab-header`, `.lab-nav`, `.group-header-row`, and `.mode-toggle` to allow `flex-wrap: wrap`.
  - Added `@media (max-width: 600px)` phone-width rules reducing container padding and switching 4-column/5-column strips (`.joint-grid`, `.xyz-grid.four-col`, `.joint-limit-strip`, `.perf-overlay-grid`, `.form-row-3`) to `repeat(2, minmax(0, 1fr))`.
- **`PROJECT.md`**:
  - Added `M1` row in §7 with status `done`.
