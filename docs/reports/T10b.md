# Phase T10b — "Kendi kontrolcün" (Student-Written JavaScript Controller)

## 1. What Changed
- **`src/RobotArm.Web/wwwroot/js/custom-controller.js` (new)**:
  - Implements the browser-local JavaScript control runtime (`RobotArmCustomController`) and Web Worker pre-run dry-run verifier.
  - Compiles the student's `kontrol(t, q, qd, ref, model)` function via `new Function(...)` under `"use strict"`.
  - Exposes `model.M(q)`, `model.gravity(q)`, and `model.bias(q, qd)` which call back synchronously into .NET (`JsController`), plus `model.kp`, `model.kd`, `model.ki`.
  - Implements `dryRunInWorker(sourceCode, kp, kd, ki)`: spawns an isolated Web Worker (`Blob` URL) that executes 2000 calls with representative inputs under a 500 ms wall-clock timeout. If compilation fails, an exception is thrown, the return value is not a 4-element array of finite numbers, or execution exceeds 500 ms (such as an infinite loop `while (true) {}`), the worker is terminated via `worker.terminate()` and the run is refused with a Turkish error message without freezing the main UI thread.
  - Implements `invokeKontrol(t, q, qd, qRef, vRef, aRef)` returning `[u0, u1, u2, u3, okFlag]` (always finite numbers so `System.Text.Json` never fails to deserialize `NaN`).
- **`src/RobotArm.Web/Models/JsController.cs` (new)**:
  - Implements `RobotArm.Core.Control.IController` (`DegreesOfFreedom = 4`, `Clamped`, `Reset()`, `Compute(...)`) in `RobotArm.Web` without modifying `RobotArm.Core`.
  - Provides `[JSInvokable]` callbacks `ComputeM(double[] q)`, `ComputeGravity(double[] q)`, and `ComputeBias(double[] q, double[] qd)` computed from `ControllerBelief` via `RecursiveNewtonEuler.InertiaMatrix` and `RecursiveNewtonEuler.BiasTorque` (never from the true plant). Updates `Belief` on `SetPayloadBelief(double payloadKg)` when `PickPlace` attaches/releases under `PayloadKnowledge.Informed`.
  - Checks every sample return value: if `okFlag != 1.0` or any element is non-finite, throws `CustomControllerFaultException("Kontrolcün sayı olmayan bir değer döndürdü")`; clamps finite outputs to $\pm\tau_{\max}$ (`±4.1 N·m`) and sets `Clamped[i]`. Records a Turkish warning (`SlowCallWarning`) if any call takes longer than `5 ms`.
  - Defines the three Turkish-commented example laws in `CustomControllerExamples.All`:
    1. `pdg`: PD + gravity compensation (`CustomControllerExamples.DefaultPdgCode`, default prefilled code).
    2. `ct`: Computed torque by hand (`CustomControllerExamples.CtByHandCode`, using `model.M(q)` and `model.bias(q, qd)`).
    3. `smc`: Sliding-mode control with a boundary layer (`CustomControllerExamples.SlidingModeCode`, $s = \dot{e} + \lambda e$).
- **`src/RobotArm.Web/Models/CustomExperimentRunner.cs` (new)**:
  - Executes the deterministic step/sample loop for `JsController` matching `ExperimentRunner`, catching `CustomControllerFaultException` and stopping cleanly with `Fault(FaultReason.NonFinite, t, -1, double.NaN)` and failure reason `"Kontrolcün sayı olmayan bir değer döndürdü"`.
- **`src/RobotArm.Web/Models/LabState.cs`**:
  - Added `UseCustomController`, `SelectedCustomExampleKey`, `CustomControllerCode`, `CustomControllerError`, `CustomControllerSlowWarning`, `SerializeScenarioWithCustomController`, and `DeserializeScenarioWithCustomController` (persisting `"customController"` in exported scenario JSON and stripping it before `ScenarioJson.Deserialize`).
  - Updated `TranslateFailureOrFault` so `"Kontrolcün sayı olmayan bir değer döndürdü"` is displayed verbatim in Turkish.
- **`src/RobotArm.Web/Components/SetupPanel.razor`, `src/RobotArm.Web/Pages/Home.razor`, `src/RobotArm.Web/wwwroot/index.html`, `src/RobotArm.Web/wwwroot/css/app.css`**:
  - Added `"Kendi kontrolcün (JavaScript)"` to `#controller-select`, the preset law selector `#custom-law-preset-select`, the monospace code editor `#custom-controller-editor`, error/warning banners, pre-run Web Worker dry run, and JSON export/import integration.
- **`docs/DECISIONS.md` & `PROJECT.md`**:
  - Added decision entry `D12` and marked `T10b` as `done` in `PROJECT.md` §7.
