## 2. Manual Repository Configuration Steps (`Settings → Pages`)

1. Open the repository on GitHub (`https://github.com/<user>/robot-kol-sanal-lab`).
2. Click **Settings** in the top repository navigation bar.
3. In the left sidebar under **Code and automation**, click **Pages**.
4. Under **Build and deployment → Source**, change the dropdown from `Deploy from a branch` to **`GitHub Actions`**.
5. Push to `main` (or trigger **Deploy to GitHub Pages** manually from the **Actions** tab via **Run workflow**). Once the workflow completes, the laboratory will be live at `https://<user>.github.io/robot-kol-sanal-lab/`.

> **Private Repository Note:** Publishing a GitHub Pages site from a **private** repository requires a paid plan (**GitHub Pro**, **GitHub Team**, or **GitHub Enterprise**) or **GitHub Education** (Student / Teacher Pack) benefits. On a free personal account without GitHub Education, either upgrade / apply GitHub Education benefits or change repository visibility to **Public** under **Settings → General → Danger Zone → Change repository visibility** so GitHub Pages is available at no cost. Also note that even on a private repository with GitHub Pro/Education, the published GitHub Pages site itself is publicly reachable on the internet unless GitHub Enterprise access control is enabled.
