# Phase A2 Report — Linear Analysis Page `/analiz` (Web)

## 1. Summary of Changes
- **`src/RobotArm.Web/Layout/MainLayout.razor`**: Added the `Analiz` navigation link (`/analiz`) to the main header menu.
- **`src/RobotArm.Web/_Imports.razor`**: Added `@using System.Numerics` and `@using RobotArm.Core.Analysis`.
- **`src/RobotArm.Web/Models/LabState.cs` & `src/RobotArm.Web/Pages/Home.razor`**: Added `IsSimulationRunning` state synchronization and public helpers (`GetTruePlanet()`, `GetInitialPlantPayloadKg()`, `BuildControllerBelief()`, `BuildLinearisableController()`) so `/analiz` shares the live setup with `/` and suspends calculations while a simulation run is active.
- **`src/RobotArm.Web/Models/AsyncGainTuner.cs`**: Added an asynchronous wrapper around `GainTuner` (`GainTuner.Evaluate`, `SampledLoopModel.ForArm`, `LinearAnalysis.ClosedLoopPoles`, `LoopFrequencyResponse.Compute`) that yields (`await Task.Delay(1)`) between candidate evaluations so the Blazor UI, progress bar, and `İptal` button stay responsive while producing the exact deterministic Nelder–Mead sequence of `GainTuner.Tune`.
- **`src/RobotArm.Web/Pages/Analysis.razor`**: Created `/analiz` with Turkish UI, editable analysis pose $q_0$, 300 ms input debounce + on-demand `Hesapla` button, `Performans` timing overlay, and all six panels using the existing `Plot` component, each with a 2–3 sentence *"Bu grafik ne gösterir?"* note in plain Turkish:
  1. **Kutup Haritası (`SampledLoopModel.ForArm`, `LinearAnalysis.ClosedLoopPoles`)**: Equal-aspect z-plane pole map with the unit circle, table of $z, |z|, s = \ln(z)/T_s, \omega_n, \zeta$, and green/red $\rho$ badge.
  2. **Kök Yer Eğrisi (`RootLocus.Sweep`)**: Sweeps common scale factor $k$ (`LocusParameter.ScaleAll`) or individual joint gain ($K_p, K_d, K_i$), plots continuous pole tracks with equal aspect and unit circle, marks current poles and $|z|=1$ crossings, and reports `RootLocusResult.CriticalValue`.
  3. **Bode Diyagramı (`LoopFrequencyResponse.ComputeAll`)**: Per-joint loop-at-a-time magnitude (dB) and phase (°) on log frequency (`AxisScale.Log`), marks $\omega_{gc}$ / PM and $\omega_{pc}$ / GM, displays a clear Nyquist warning when `OpenLoopUnstablePoles > 0`, and includes a 4-joint summary table.
  4. **Doğrusal ve Doğrusal Olmayan Karşılaştırma (`LinearStepResponse.Compute` + nonlinear `Simulation`/`ControlLoop`)**: Joint and step size (`0.003`, `0.01`, `0.1`, `0.5` rad) selector, overlays linear and nonlinear step responses, and reports peak % difference.
  5. **Ayrık Zamanlı LQR (`DiscreteLqr.ForArm`)**: Per-joint $Q$ (position and velocity) and $R$ weight inputs, equal-aspect pole map comparing full-state ($4 \times 8$) LQR poles and diagonal projection ($K_{p,i} = K_{i,i}, K_{d,i} = K_{i,4+i}$) poles and $\rho$, and `"Köşegen kazançları uygula"` button writing $K_p/K_d$ back to `LabState`.
  6. **Otomatik Kazanç Ayarı (`GainTuner` via `AsyncGainTuner`)**: Multi-select scenarios from `ScenarioLibrary.All`, sensor mode (`TuningSensorMode.Scenario` / `TuningSensorMode.PerfectAndEncoder`), cost aggregation (`TuningCostAggregation.Sum` / `TuningCostAggregation.Max`), minimum GM and PM, max evaluations, `Başlat` / `İptal`, progress bar, best-cost history plot, baseline vs. best results table, and `"Kazançları uygula"` button.
- **`src/RobotArm.Web/wwwroot/css/app.css`**: Added responsive layout and panel styles for `/analiz`.
- **`docs/screenshots/A2-analiz.png`**: Saved full-page screenshot of `/analiz`.
- **`PROJECT.md`**: Added row `A2` set to `done` in §7.
